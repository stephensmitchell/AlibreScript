# Alibre Script Examples, Demos, and Experiments

Examples, demos, experiments, API references, and stub files for Alibre Script. The focus is Alibre Script with IronPython 2.7.10 compatibility.

## Contents

- Alibre-Script.Reflected: Python stub source generated by .NET reflection of AlibreScriptAddOn.dll.
- Alibre-Script-Code-Assistant: example seeds from a custom GPT; unverified, so validate before reuse.
- Alibre-Script-VSCode: a VS Code workspace setup for Alibre Script development.
- alibre-script.api.text: Alibre Script API exports in text and CSV, plus LLM/agent docs and stub-generator tools.
- Alibre-Script-Stub-Files: generated and source Python stub files for editor support (autocomplete, Pylance/Pyright) when working outside Alibre Design.
- alibre-script-library-examples: larger library-style example scripts.
- alibre-script-examples: example scripts from the Alibre Script documentation.
