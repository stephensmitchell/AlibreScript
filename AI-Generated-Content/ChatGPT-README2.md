# Alibre Script Examples, Demos, and Experiments

Alibre Script examples, demos, experiments, API references, and stub files. Everything here targets Alibre Script with IronPython 2.7.10 compatibility.

## Components

- **Alibre-Script.Reflected/**
  - Python stub source generated by .NET reflection of `AlibreScriptAddOn.dll`.
- **Alibre-Script-Code-Assistant/**
  - Example seeds from a custom GPT. Unverified; validate before reuse.
- **Alibre-Script-VSCode/**
  - A VS Code workspace setup for Alibre Script development.
- **alibre-script.api.text/**
  - Alibre Script API exports in text and CSV, plus LLM/agent docs and stub-generator tools.
- **Alibre-Script-Stub-Files/**
  - Generated and source Python stub files for editor support (autocomplete, Pylance/Pyright) when working outside Alibre Design.
- **alibre-script-library-examples/**
  - Larger library-style example scripts.
- **alibre-script-examples/**
  - Example scripts from the Alibre Script documentation.
