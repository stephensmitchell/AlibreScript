# Alibre Script Project Summary

## Overview

Alibre Script examples, demos, experiments, API references, and stub files for Alibre Design, a 3D CAD program. The scripts target Alibre Script and IronPython 2.7.10.

### Components

1. **Alibre-Script.Reflected**
   - Python stub source generated by .NET reflection of AlibreScriptAddOn.dll.
2. **Alibre-Script-Code-Assistant**
   - Example seeds from a custom GPT. These are unverified. Validate before reuse.
3. **Alibre-Script-VSCode**
   - A VS Code workspace setup for Alibre Script development.
4. **alibre-script.api.text**
   - Alibre Script API exports in text and CSV, plus LLM/agent docs and stub-generator tools.
5. **Alibre-Script-Stub-Files**
   - Generated and source Python stub files for editor support such as autocomplete, Pylance, and Pyright when you work outside Alibre Design.
6. **alibre-script-library-examples**
   - Larger library-style example scripts.
7. **alibre-script-examples**
   - Example scripts from the Alibre Script documentation.

## Target Audience

Alibre Design users who script tasks, write custom functions, or connect the CAD program to other software tools.
